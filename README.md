# 屏東廠藥品品質抽查表（Rev.08）行動網頁版

每週藥品品質抽查用手機填寫，資料存在 Google Sheet，可以一鍵輸出和原本 Excel 相同版面的週報。

- 前端：GitHub Pages（本 repo）
- 後端：Google Apps Script（`apps-script/Code.gs`），帳號 `dachanqa@gmail.com`
- 輸出檔名：`屏東廠藥品品質抽查表(Rev.08)` + 民國年 + ISO 週次，例如 `…11547.xlsx`

## 第一次部署（只做一次）

### 1. 建立 Google Sheet 和 Apps Script
1. 用 `dachanqa@gmail.com` 新增一份 Google 試算表，名稱例如「藥品品質抽查資料」。
2. 選單「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 的內容整個貼上，取代預設程式碼。
3. 修改最上面兩組密碼：`PASSWORD`（填表用）、`ADMIN_PASSWORD`（上傳覆蓋資料用）。
4. 上方函式選單選 `setup`，按「執行」，依畫面授權。執行後試算表會出現各分頁。
5. 右上角「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：**我**
   - 存取權：**所有人**
6. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。

### 2. 設定網頁
打開 GitHub Pages 網址，按右上角「設定」，貼上 `/exec` 網址和填表密碼，按「儲存並連線」。
設定會存在那支手機的瀏覽器；也可以把網址寫進 `config.js` 的 `API_URL`，大家就只要輸入密碼。

### 3. 匯入資料
按右上角「上傳」，選 11547 那份 Excel，輸入管理密碼後上傳。
系統會依分頁名稱（Sheet3、Sheet1、工作表1、Sheet5、公司藥主檔）**整張覆蓋** Google Sheet 對應的分頁，覆蓋前自動備份（每個分頁保留最近 3 份，隱藏在試算表裡）。
如果「公司藥主檔」是空的，會先用工作表1 的品項建立初稿，請再到 Google Sheet 補齊、把停用的藥「是否啟用」改成 `N`。

## 每週使用
1. 選抽查日期（畫面顯示週次）。
2. 客戶藥：「一鍵隨機抽 5 筆」，只抽效期未過、庫存 > 0、還沒查過（藥名 + 客戶）的品項；可逐筆「換一筆」或「選擇」。
3. 公司藥：從主檔「啟用」的藥抽或選，現場查核後輸入有效日期。
4. 檢查外觀、效期、檢驗報告（自動比對 Sheet5，取判定日期最新的一筆；查不到時列出相近品名讓你確認）。
5. 「送出並下載 Excel」：寫入「抽查紀錄」，並把品項附加到 Sheet1／工作表1。

### 判定規則
任一項成立就自動判為不合格，可以手動改，但手動改要在備註寫原因：
- 外觀異常
- 效期早於抽查日期
- 客戶藥的檢驗報告為「否」（包含 Sheet5 查無紀錄）

公司藥 Sheet5 查得到就填，查不到留白，不影響判定。

### 不合格率
- 本週 = 本週不合格數 ÷ 10
- 本月累計：同一個月的週報依日期排成第一～第五週，換月自動重新開始。
